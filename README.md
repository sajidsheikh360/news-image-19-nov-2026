## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node.js, standard library only, no network use) copies `entry.png`
into `$MAKEFUN_OUTPUT_DIR` (or `/output` when unset) as `entry.png`. Running it
twice produces byte-identical output.
